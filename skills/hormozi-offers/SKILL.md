# Hormozi Offers

Diagnose and strengthen offers using Hormozi's value equation, grand slam offer, and enhancement frameworks.

## Use Cases

- Improve this offer
- Rewrite this package so it feels irresistible
- What guarantee or bonus should we add?

## Primary Outputs

- value-equation diagnosis
- offer stack
- guarantee/bonus/scarcity set
- naming shortlist

## Hard Boundaries

- Not primary acquisition-channel strategy
- Not full ad creation
- Not full-funnel monetization design

## Composition

- Composes with: `hormozi-pricing`, `hormozi-hooks`, `hormozi-launch-campaigns`
- Preferred sequence: Use first when offer quality is the bottleneck, then hand off to pricing, hooks, or launch skills as needed.
