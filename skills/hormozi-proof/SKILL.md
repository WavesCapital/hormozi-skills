# Hormozi Proof

Audit and improve proof, trust, and credibility systems.

## Use Cases

- What proof are we missing?
- Help organize testimonials for this sales page
- Why don't prospects believe this claim?

## Primary Outputs

- proof-gap audit
- testimonial asset map
- trust stack by funnel stage
- proof placement plan

## Hard Boundaries

- Not core offer redesign
- Not full brand strategy
- Not standalone close-script work

## Composition

- Composes with: `hormozi-offers`, `hormozi-goated-ads`, `hormozi-branding`
- Preferred sequence: Use when trust, credibility, or proof placement are the bottlenecks.
