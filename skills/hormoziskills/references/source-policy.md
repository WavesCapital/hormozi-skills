# Source Policy

This skill framework can be shared publicly, but the original Hormozi/Acquisition source materials are not bundled in the public release by default.

Rules:

- Treat original source materials as user-supplied unless redistribution rights are explicitly documented.
- Do not publish raw PDFs, DOCX files, media files, or full extracted raw markdown from proprietary materials.
- Public releases may ship only the authored skill framework, catalog, router logic, templates, and safe examples.
- If local source hydration is needed, import those files from a private, gitignored path on the user's machine.
