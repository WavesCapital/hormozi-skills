# Public Release Model

Use a `public core + private overlay` release model.

Public repo:
- SKILL.md files
- agents/openai.yaml
- catalog and routing docs
- setup/import scripts
- public README and install docs

Private overlay:
- extracted raw source markdown
- proprietary source ownership internals
- copyrighted launch assets and scripts

Never publish raw private source material directly from the working tree.
Publish only from a sanitized artifact.
