        # Hormozi Branding Framework

        ## Job
        Build fame, authority, association, and brand-driven demand.

        ## Use Cases
        - Make this brand more memorable
- How do we become the obvious name in this category?
- What associations should our brand build?

        ## Outputs
        - brand association map
- fame/authority strategy
- brand-to-sales translation memo
- pivot/growth plan

        ## Hard Boundaries
        - Not short-term direct-response ad production
- Not offer/pricing diagnosis
- Not launch ops

        ## Composition
        - Composes with: hormozi-proof, hormozi-goated-ads, hormozi-launch-campaigns
        - Preferred sequence: Use when the constraint is memorability or long-horizon demand, not short-term conversion.
        - Fallbacks: none
