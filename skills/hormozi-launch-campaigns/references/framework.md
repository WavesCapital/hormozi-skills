        # Hormozi Launch Campaigns Framework

        ## Job
        Design launches, affiliate systems, VSL funnels, and page-flow orchestration.

        ## Use Cases
        - Plan a live launch funnel for this product
- Build the affiliate rollout and prize structure
- Map the registration-to-upsell page flow

        ## Outputs
        - launch architecture/calendar
- page-flow and VSL map
- affiliate plan
- run-of-show and launch ops brief

        ## Hard Boundaries
        - Not evergreen acquisition by default
- Not generic ad work outside launch context
- Not standalone pricing/closing except launch-specific adaptations

        ## Composition
        - Composes with: hormozi-offers, hormozi-lead-nurture, hormozi-closing
        - Preferred sequence: Use when the work is explicitly launch, campaign, event, funnel, or affiliate driven.
        - Fallbacks: none
