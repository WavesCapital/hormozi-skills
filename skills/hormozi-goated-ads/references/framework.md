        # Hormozi GOATed Ads Framework

        ## Job
        Turn offers into ad concepts and creative testing plans using GOATed Ads structure.

        ## Use Cases
        - Turn this offer into 12 ad concepts
- Make paid social ads that can scale
- Generate hook/meat/CTA variants

        ## Outputs
        - ad concept matrix
- hook/meat/CTA set
- creative batch brief
- testing plan

        ## Hard Boundaries
        - Not channel-selection strategy
- Not pure-hook generation only
- Not launch-funnel orchestration

        ## Composition
        - Composes with: hormozi-hooks, hormozi-leads, hormozi-proof
        - Preferred sequence: Use after the offer and audience are clear.
        - Fallbacks: none
