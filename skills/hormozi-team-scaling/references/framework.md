        # Hormozi Team Scaling Framework

        ## Job
        Install team communication, service, and operating-system frameworks for scale.

        ## Use Cases
        - Install a better weekly management cadence
- Service quality is slipping as we scale
- How should raises work on this team?

        ## Outputs
        - operating cadence plan
- framework rollout plan
- manager toolkits
- implementation SOP outline

        ## Hard Boundaries
        - Not stage diagnosis
- Not sales/marketing execution
- Not broad HR/legal policy design

        ## Composition
        - Composes with: hormozi-scaling-roadmap, hormozi-closing
        - Preferred sequence: Use after the stage is known and the team-system bottleneck is clear.
        - Fallbacks: hormozi-scaling-roadmap
