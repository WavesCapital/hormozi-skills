
# Public Hormozi Skills

Public-safe release of the Hormozi skill framework.

Included:
- `hormoziskills` router skill
- public-safe `hormozi-*` child skills
- public catalog and routing rules
- install and architecture docs

Excluded:
- raw source PDFs, DOCX files, spreadsheets, images, audio, and video
- extracted raw markdown from proprietary/private materials
- private source-ownership internals

These skills are designed to work as a public framework. If source-backed behavior is needed, import licensed source materials locally on your own machine.
